إدارة الروابط

للحفاظ على الأمان، لا توجد كلمة مرور داخل الموقع. أنت تعدّل ملف links.json من مستودع GitHub الخاص بك، والزوار يشاهدون الروابط فقط.

طريقة التعديل
  1. افتح ملف links.json في GitHub.
  2. اضغط علامة القلم ✏️.
  3. أضف أو عدّل أو احذف رابطاً.
  4. اضغط Commit changes.
  5. سيظهر التحديث على الموقع بعد نشر GitHub Pages.
